# 기사 프로젝트 노트

기사 프로젝트의 진행 상황을 한 페이지에 정리하는 노트 페이지예요. 설치나 빌드 없이 `index.html` 파일 하나로 동작해요.

## 구성

| 칸 | 설명 |
| --- | --- |
| 프로젝트 한 줄 | 프로젝트를 한 줄로 소개하는 칸 |
| 이름과 역할 | 이름과 맡은 역할을 적는 칸 |
| 주제 | 대주제를 적는 칸 (세부 주제는 "내일 정함"으로 표시) |
| 할 일 체크리스트 | 체크박스가 있는 5개의 칸 |
| 날짜별 기록 | 세로선 위에 날짜가 점으로 찍히는 타임라인 (11/18부터 시작) |

## 특징

- **파일 하나**: `index.html` 하나로 끝나요. 별도의 라이브러리가 필요 없어요.
- **모바일 대응**: 휴대폰 화면에서도 읽기 편하게 만들었어요.
- **바로 입력**: 칸을 눌러서 바로 적을 수 있어요.
- **자동 저장**: 적은 내용은 사용하는 기기의 브라우저(localStorage)에 저장돼요. 서버로 보내지 않아요.
- **개인정보 칸 없음**: 전화번호나 주소 같은 칸은 만들지 않았어요.

## 사용 방법

1. 저장소를 내려받거나 `index.html`을 다운로드해요.
2. `index.html`을 브라우저로 열어요.
3. 칸을 눌러 내용을 적어요. 날짜를 더하려면 "+ 날짜 추가"를 눌러요.

## 깃허브 페이지로 공개하기

1. 이 저장소의 루트에 `index.html`을 올려요.
2. 저장소의 **Settings → Pages**로 들어가요.
3. **Source**를 `Deploy from a branch`로 두고, 브랜치를 `main`, 폴더를 `/ (root)`로 선택한 뒤 저장해요.
4. 잠시 뒤 안내되는 주소에서 페이지를 볼 수 있어요.

## 참고

- 입력한 내용은 기기와 브라우저마다 따로 저장돼요. 다른 기기에서 열면 비어 있어요.
- 브라우저의 사이트 데이터를 지우면 저장된 내용도 함께 지워져요.
